# 弹性组合管理页面使用指南

> 本文档介绍弹性组合管理页面的布局结构、核心概念与操作方式。
> 源码位置：[portal-flexible-combination-manager.js](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js)
> 菜单配置：[explorer-menu.json](file:///media/yqs/工作/rustspace/cmx/cmx-container/data/menu-pages/fi/cmxfico/gl/explorer-menu.json)

## 一、整体布局：三栏 Workspace

页面采用三栏 workspace 布局：

| 区域 | 位置 | Tab 页 | 组件 |
|------|------|--------|------|
| **Explorer** | 左侧栏 | 档案 | `portal-flexible-combination-list` |
| **Content** | 中间主体 | 设计 / 源码 / Schema | `portal-flexible-combination-manager` / `-source` / `-schema` |
| **Property** | 右侧栏 | 检查器 / 校验预览 | `portal-flexible-combination-inspector` / `-verify` |

三栏通过模块级单例 `combinationBus`（EventTarget）联动，列表与主体分属不同 ShadowDOM 子树，通过总线同步状态与事件（[代码注释](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L8-L31)）。

## 二、左侧栏：档案列表

组件：[PortalFlexibleCombinationList](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L4185)

- **筛选器**：按 Domain / App / Module 三级过滤
- **档案列表**：每项是一个弹性组合档案（由 DAM + scenario 定位）
- **操作**：
  - 点击选中 -> 主体加载该档案
  - 「新建」创建空档案
  - 「刷新」重拉列表

## 三、中间主体

### 3.1 设计 Tab（核心区域）

渲染逻辑：[_renderDesigner](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L1858-L1900)，从上到下分为：

#### 面板头（toolbar）

[panel-head 代码](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L1371-L1381)：

- **标题**：当前档案名（未保存时显示 `*`）
- **引用单据**：关联业务单据（CmxDOCMeta），关联后才能按表建规则面板
- **版本控制**：版本下拉切换 + 版本管理 + 新建版本（[_renderVersionControl](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L1600-L1617)）
- **操作按钮**：校验 / 预览 / 删除 / 保存

#### 维度区（可折叠）

[_renderDimensionsTable](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L1420)

维度是弹性组合的"上下文变量"（如科目、交易类型）。表格列：`编码 / 名称 / 属性`，每个维度可关联数据字典。点击维度行 -> 右侧检查器显示该维度引用字典的列信息。

#### 规则面板区（Tab 分组）

这是设计的核心，结构为 **面板(Tab) -> 规则(行) -> 字段集(Tab) -> 字段(行)**：

```
┌─────────────────────────────────────────────┐
│ 规则面板 Tab：[表A] [表B] ＋           ← 每个面板关联一张单据表
├─────────────────────────────────────────────┤
│ 规则表格（多行）                              │
│ # | 规则ID | 名称 | 锚点维度 | 锚点列 | 匹配JSON | 操作 │
│  1 | ...                                    │
├─────────────────────────────────────────────┤
│ 字段集 Tab：[字段集1] [字段集2] ＋  📋📋   ← 每个字段集关联一张表
├─────────────────────────────────────────────┤
│ 字段表格（多行）                              │
│ # | 字段ID | 标题 | 类型 | ... | 操作        │
├─────────────────────────────────────────────┤
│ ▸ 分组（可折叠）                              │
│ ▸ 列模型属性（可折叠）                         │
└─────────────────────────────────────────────┘
```

**规则表格**（[_renderRulesTable](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L2131-L2154)）

每条规则定义"当维度匹配某值时，生成哪些列"。列含锚点维度、锚点列、匹配 JSON。操作：选中 / 上移 / 下移 / 删除。

**字段集 Tab**（[_renderFieldTabsArea](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L2074-L2108)）

一条规则可含多个字段集，每个关联一张表。支持复制/粘贴字段。

**字段表格**（[_renderFieldsTable](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L2156-L2170)）

由统一 schema 渲染器产出。点击字段行右侧「检查器」图标 -> 右侧检查器编辑该字段高级配置。

**分组**（[_renderGroups](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L2507-L2538)）

字段分组 + 聚合（合计/平均/最大/最小/计数），支持嵌套子分组。

**列模型属性**（[_renderColumnModelPanel](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L2551-L2567)）

分档案级和规则级覆盖，配置 caption / datasetId / toTitleCols / iconCol。

### 3.2 源码 Tab

组件：[PortalFlexibleCombinationSource](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L3907)

### 3.3 Schema Tab

组件：[PortalFlexibleCombinationSchema](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L4105)

只读的完整 schema 视图，继承自 Source，关键区别：`EditorView.editable.of(false)`。

- 获取文本：[getSchemaText](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L1825-L1827) -> [buildContextResolvedSchema](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L4058-L4100)

### 3.4 源码与 Schema 的区别

| 对比项 | 源码 | Schema |
|--------|------|--------|
| **内容** | 原始组合数据（`normalizeCombination` 序列化） | 引擎编译 + 合并单据元数据后的完整结构 |
| **可编辑** | 可编辑，修改回写 `_combination` | 只读 |
| **独有内容** | 无 | `schemaKind`、`docSchema`（单据元数据）、`fieldSets[].columns/members/columnModel`（引擎编译展开结果） |
| **用途** | 编辑档案的原始 JSON（输入） | 查看引擎编译后最终生效的完整结构（输出） |

## 四、右侧栏

### 4.1 检查器

[_renderInspector](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L2469-L2503) 根据当前选中元素**动态切换内容**：

| 选中元素 | 检查器显示 |
|---------|-----------|
| 字段（点字段行检查器图标） | 字段高级配置面板（renderFieldPanel） |
| 规则行 | 规则定义编辑器（含 match 编辑） |
| 维度行 | 该维度引用字典的列信息（只读） |
| 单据表（view 下拉点表） | 该表列定义（只读，按 fieldSet 分组） |
| 单据整体信息 | 模块元信息 + 层级/表清单概要 |
| 引用字典联查 | 钻取的字典列定义 + 返回按钮 |

### 4.2 校验/预览

点工具栏「校验」或 property 区「校验/预览」面板的按钮后，结果以**弹窗**展示（`showCmxMessage` / `cmx-floating-dialog`），不再用底部占位横幅：

- **校验**：弹窗展示完整诊断明细——错误逐条（✕ 路径 描述）、警告逐条（⚠ 路径 描述）；通过时弹信息级"校验通过"。底部消息条不再重复提示。
- **预览**：弹窗展示匹配规则（ruleId）+ 列模型 JSON + 成员明细 JSON。底部消息条不再重复提示。

> property 区「校验/预览」面板仍保留锚点输入 + 诊断 + 预览的常驻展示区（供对照编辑用），与弹窗的即时反馈互补。

## 五、引用单据

### 5.1 什么是引用单据

引用单据 = 关联一个业务单据定义（CmxDOCMeta），为弹性组合提供**表结构元数据支撑**。加载逻辑在 [_loadDocMeta](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L817-L834)，通过 `/api/definitions/config` 拉取单据全文。

### 5.2 选择与不选的区别

| 能力 | 引用了单据 | 不引用 |
|------|-----------|--------|
| **维度来源** | 自动派生：从单据各表的 `dimType=dimension` 字段自动生成维度池，含字典关联 | 手动逐个添加维度编码/名称/属性 |
| **新建规则面板** | 弹出表树下拉，选一张单据表建面板，面板名=表名 | 回退到 `window.prompt` 手工输入面板名 |
| **更换面板关联表** | 弹下拉选另一张表 | 手工改名 |
| **字段集关联表** | 从单据表列表中选表建立字段集 | 无表可选，手工配置 |
| **列校验** | 校验锚点列是否在表中、字段绑定列是否在表中、overlay 引用诊断（断表/断列/物理类型） | 跳过所有表结构校验（`hasDoc=false`） |
| **检查器查看** | 可查看单据整体信息、各表列定义、钻取引用字典 | 无此功能 |
| **Schema 合并** | `buildContextResolvedSchema` 合并单据元数据 | 仅纯弹性组合自身结构 |

关键代码：
- 维度自动覆盖：[_setDocRef:873-886](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L873-L886)
- 面板新建分叉：[_addPanel:2810-2826](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L2810-L2826)
- 校验分叉：[_clientDiagnostics:960-1008](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L960-L1008)

### 5.3 一句话总结

- **引用单据** = 有表结构元数据支撑，维度自动派生、面板/字段集按表关联、列校验完整
- **不引用** = 纯手工配置，无表结构校验，适合不依赖业务单据的独立弹性组合场景

## 六、关联表的设置方式

关联表**不是输入框直接编辑**，而是通过 **tab 上的"✎"按钮** 来设置/更换。有两个层级：

### 6.1 规则面板的关联表

[代码 1887-1889](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L1887-L1889)：

```
[ 表别名(3) ＋ ✎ ✕ ]   ← 只有选中(高亮)的面板才显示这三个按钮
```

- tab 显示的是**表别名**（[_panelLabel](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L1944-L1951) 把表名转为别名）
- 点 **"✎"**（tooltip="更换关联表"）-> 弹出表树下拉，选另一张表更换

### 6.2 字段集的关联表

[代码 2080-2083](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L2080-L2083)：

```
[ 表别名(5) ＋ ✎ ✕ ]   ← 同样只有选中的字段集才显示
```

- 点 **"✎"**（tooltip="更换关联表/改名"）-> 弹出表树下拉选表

### 6.3 操作步骤

1. **先点击选中**某个面板 tab 或字段集 tab（让它高亮）
2. 选中后 tab 右侧出现 **＋ ✎ ✕** 三个小按钮
3. 点 **✎** 弹出表树选择器，从中选一张表

> 前提：必须已引用单据。未引用时点"✎"回退为 `window.prompt` 手工输入名称（[_renamePanel:2829-2852](file:///media/yqs/工作/rustspace/cmx/CMXPortalManager/src/components/portal-flexible-combination-manager.js#L2829-L2852)），且只是改个名字，没有真正的表结构关联。

## 七、核心概念速览

| 概念 | 含义 |
|------|------|
| **DAM** | Domain / App / Module，定位后端存储位置 |
| **scenario** | 业务场景（如 account / trade），同一 DAM 可有多个版本 |
| **维度（Dimension）** | 上下文变量（如科目=1122），决定列怎么变 |
| **规则（Rule）** | "当维度匹配某值 -> 生成这些列"的条件定义 |
| **字段集（FieldSet）** | 规则下的字段分组，每个关联一张单据表 |
| **分组（Group）** | 字段的展示分组 + 聚合（合计/平均等） |
| **引用单据（docRef）** | 关联业务单据定义，提供表结构元数据 |

## 八、典型操作流程

1. 左侧列表**选中或新建**档案
2. 标题栏**引用单据**（关联业务单据，获取表定义）
3. **定义维度**（上下文变量，可关联数据字典；引用单据后自动派生）
4. **新建规则面板**（选一张单据表关联）
5. 面板内**新增规则**（设锚点维度 + 匹配条件）
6. 为规则**新建字段集**（选表）并**添加字段**
7. 可选：配置**分组**和**列模型属性**
8. 点**保存**

> **一句话理解**：弹性组合 = "选了什么科目/交易类型 -> 表格列就自动变成什么" 的配置工具。维度是条件，规则是映射，字段是结果。
