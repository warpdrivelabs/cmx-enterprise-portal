# lib 目录模块总览（packages/cmx-data-comp/src/lib）

> cmx-data-comp 组件库的**核心逻辑层**，53 个 JS 模块（不含 `__tests__/`）。全部与渲染层解耦的纯逻辑：数据容器、列模型、元数据、字段属性面板、数据装载、弹性组合引擎、公式求值、运行时桥接等。组件外壳（`src/components/*.js`）消费这些模块。

## 1. 数据容器

数据树的最底层结构，`CmxRowSet` → `CmxDataSet` → `CmxDataSetView`。无 Proxy、V8 可完整优化。

| 文件 | 行 | 职责 |
|---|---|---|
| `cmx-row-set.js` | 53 | **CmxRowSet** — 数据树中一行的容器。字段值直接作为实例属性存储；`_children` 挂子 `CmxDataSet` 形成可无限深的树。修改统一调 `row.set(key, value)`，由 `_ds` 向上通知 |
| `cmx-data-set.js` | 411 | **CmxDataSet** — 多级数据集（继承 EventTarget）。内部以 `CmxRowSet[]` 存储，子层通过 `row._children[childId] = CmxDataSet` 形成树。变更派发 `row-changed` / `ds-row-added` / `ds-row-removed` / `cursor-changed` 事件 |
| `cmx-data-set-view.js` | 248 | **CmxDataSetView** — 数据集的「过滤视图」（零拷贝）。`_rows` 只存主集 `CmxRowSet` 的引用，不复制字段数据；写操作委托主集，是投影不独立增删 |

## 2. 列模型体系

与渲染层无关的纯列元数据，通过 `toDescriptors()` 输出通用中间格式，再由适配器转具体 grid。

| 文件 | 行 | 职责 |
|---|---|---|
| `cmx-column.js` | 246 | **CmxColumn** — 单列定义对象。`id` 即字段名、`caption` 即标题。所有显示/编辑设置收敛到声明式 `display{}` / `edit{}` 两组结构化配置 |
| `cmx-column-group.js` | 161 | **CmxColumnGroup** — 列分组定义。组织若干 `CmxColumn`/嵌套分组为带标题分组，支持分组内聚合（sum/avg/max/min/count），聚合位置可前可后 |
| `cmx-column-model.js` | 239 | **CmxColumnModel** — 列模型。把 `CmxColumn` 和 `CmxColumnGroup` 组织为完整列配置方案，派发 `columns-changed` 通知所有订阅的可视组件重渲染 |
| `cmx-column-adapter.js` | 902 | **CmxColumnAdapter** — 列描述符适配器。把 `toDescriptors()` 转为具体 grid 格式：`toRevoGrid()` / `toCmxFormGrouped()` / `toAgGrid()`。**含 `formatByPreset` / `formatDateValue` 格式化引擎** |
| `cmx-column-presets.js` | 206 | 列函数预设注册表。替代直接接收 function（onChange/formatter/display），改为声明式 `{ preset, args }`，便于 JSON 序列化、Designer 可视化配置、零代码出码 |

## 3. 主从协调器

| 文件 | 行 | 职责 |
|---|---|---|
| `cmx-master-slave.js` | 1530 | **CmxMasterSlave** — 主从多表数据协调器。持有递归主从数据树，按 path 注册表单/表格视图，管理每个 path 的当前选中行，级联刷新下级 view，监听单元格变更运行聚合规则。业务无感（schema/path/字段名全由调用方决定） |

## 4. 元数据模型基类

后端元数据 JSON 把可复用字段组存为 fieldSets，表级字段引用这些 set。本层保持每个 fieldSet 只存一份。

| 文件 | 行 | 职责 |
|---|---|---|
| `cmx-meta-model.js` | 766 | **CmxBaseMeta + registerMetaModelKind** — 元数据模型原语。fieldSet 存一份、表级字段访问展开指向 owner set 的轻量条目 |
| `cmx-dct-meta.js` | 22 | **CmxDCTMeta** — 字典元模型（`kind:'DCT'`，`tableProp:'dictionaryTables'`）。继承 `CmxBaseMeta` |
| `cmx-doc-meta.js` | 35 | **CmxDOCMeta** — 单据元模型（`kind:'DOC'`，`tableProp:'voucherTables'`）。继承 `CmxBaseMeta` |

## 5. 字段属性面板渲染体系

schema 驱动的字段/列定义编辑 UI，**DCT/DOC/FLC/设计器四端共用**。详见 `20260729_字段属性面板渲染体系.md`。

| 文件 | 行 | 职责 |
|---|---|---|
| `cmx-field-schema.js` | 350 | **FIELD_SCHEMA** — 列/字段定义统一 schema（三端并集）。每属性标 `appliesTo`(端过滤) + `placement`(inline/panel) + `section` + `control` + `visibleWhen`/`enableWhen` 钩子。单一事实来源 |
| `cmx-field-adapter.js` | 202 | **makeDctAdapter / makeFlcAdapter** — 规范键 ↔ 各端存储键的读写桥接。`set()` 返回 `{ changed, relayout }`，relayout 只用于 mode 切换（防跳顶） |
| `cmx-field-ui.js` | 207 | **renderFieldPanel / renderFieldTable** — 纯函数渲染器，输出 HTML 字符串。无副作用、不挂事件、不管样式 |
| `cmx-field-meta.js` | 109 | `fieldId` / `fieldCaption` / `fieldDisplayName` 等字段元信息读写；从 `globalThis.__cmxUi5` 读当前语言 |
| `cmx-field-uicontrol.js` | 80 | **EDIT_MODES** — 录入控件（`edit.mode`）统一值域，供 DCT/DOC/FLC/Designer 共用 |
| `cmx-field-clipboard.js` | 45 | 字段复制粘贴剪贴板载荷构造（`cmx-context-fields-v1` 类型） |

| `cmx-doc-coord.js` | 114 | 单据坐标（domain/application/module/file/doc）统一处理。归一/拼 query/去重 key/合并局部全局，消除 file 空值变 "undefined" 脏值 |
| `cmx-doc-query.js` | 129 | 筛选/排序/分页 UI 状态 ↔ DocQuery JSON 纯函数助手。按元数据列 dataType 校验列名与算子，零单据专属 |

| `cmx-doc-error-presenter.js` | 155 | DCT/DOC 后端存储错误 → 专业信息对话框统一展示。`describeDocError`（纯函数）+ `presentDocError`（弹窗），收敛冲突/校验/普通三类错误判定 |
| `cmx-async-source.js` | 142 | DataSource 远程加载支撑工具：LRU 缓存 + debounce + AbortController。cmx-ui5-table/cmx-ui5-form 内部用 |
